Elastatron

This application is an Electron application which will work on both OSX and Windows.

The application is going to act as a interface to Elasticsearch endpoints.

The application will resemble a cursor style interface.

On the left side, is a small panel which relates to the configured endpoints and management of those endpoints.
THe far right is a index listing with options to manage, select etc the indexes.

The main pain concentrates on querying the data. It will be tabbed and each tab would contain a query window and a results window below.  The query window will be able to query directly and then a collective of expandable query options which are pre defined and available.

The objective for v1.0 is for read only.
